# Expert Flow — Lead Magnet Rendszer

Teljes, élesre kész lead magnet tölcsér **1–4 fős szolgáltató vállalkozóknak**, Alex Hormozi
ajánlat- és lead-magnet-elveire építve.

**Vezérelv:** ne „AI-szolgáltatást" adj el, hanem **kockázatcsökkentett, könnyű belépésű
üzletfejlesztési segítséget**. Az AI csak a háttérmotor — a kommunikáció üzleti haszonról szól.

**A tölcsér:**
Hirdetés/social → **Ügyfélút-térkép** (lead magnet) → email-sorozat → **ingyenes konzultáció**
(itt indul el élőben az első AI-munkatárs) → fő ajánlat.

## 🚀 Bevezetés lépésről lépésre (a csapatnak)

1. **Kérdőív:** építsd meg az auditot Tally/Typeform-ban (kérdések: `lead-magnet-rendszer.md` 4. rész).
2. **AI-kimenet:** kösd be a rendszerpromptot (5. rész) Make/Zapier → Claude/OpenAI API-val.
3. **PDF-térkép:** készítsd el a Canva-sablont (`canva-pdf-sablon.md`), töltsd ki az AI-kimenettel.
4. **Weboldal:** illeszd be a blokk-szövegeket (3. rész) a meglévő oldalra.
5. **Email-sorozat:** töltsd fel az 5 emailt MailerLite/ActiveCampaign-be (0/1/3/5/7 nap).
6. **Foglalás:** Cal.com / Calendly a térkép végén és minden emailben.
7. **Mérés:** állítsd be a PostHog eseményeket és a tölcsért (`posthog-meres.md`).

## ✅ Indítás előtti checklista (Hormozi)
- [ ] Üzleti probléma-központú, NEM AI-zsargon
- [ ] Valódi érték, amiért más pénzt kérne (ne PDF-reklám)
- [ ] Az ügyfél nyelvén ígér eredményt (elvesztett idő/érdeklődő)
- [ ] Ráerősít legalább 1 érték-vektorra (gyors / kockázatmentes / könnyű)
- [ ] A konzultáció végén az ügyfél MŰKÖDŐ dologgal távozik
- [ ] A fő ajánlatban van kockázatfordító garancia
- [ ] Be van állítva a mérés
